# Elizabeth Iyasere

and integration services behind them.

interfaces to ASP.NET Core APIs, SQL Server databases and Azure DevOps pipelines. Most of my
day-to-day work lives in private company repositories, so my contribution graph is a better
picture of it than the public repositories here.
